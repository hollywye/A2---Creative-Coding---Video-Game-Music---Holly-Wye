# Video Game Music
This project explores the use of Python coding as a tool for creative musical expression. Using TunePad, I created an original piece of video game-inspired music influenced by the soundtrack and atmosphere of Stardew Valley.

## General Information 
**What problem does my project intend to solve?**

The project explores the challenge of translating musical ideas into code, exploring how programming can make the composition process more efficient.

**What is the purpose of my project?**

To develop an original video game-inspired music composition using Python in TunePad while exploring creative coding techniques.

**Why did I undertake it?**

To develop my code literacy and explore how programming can be used creatively, whilst also broadening my musical knowledge. 
## Technologies Used
* Python 
* TunePad

## Features 
* Layered musical arrangement: Multiple musical sections, including an introduction, background melody, main melody, counter-melody and chord accompaniment.
* Reusable musical functions: Functions and loops used to organise, repeat and manage musical sections.
* Dynamic melody features: Different note durations, velocity adjustments and melody variations
* Automated chord inversions: A custom algorithm that generates different inversions of chords
* Smooth chord transitions: An algorithm that compares note values and selects chord arrangements with the smallest movement between consecutive chords.

## Usage
To access and run the music composition:
1. Open TunePad.
2. Open the project using the provided TunePad project link.
3. Navigate to the code sections within the project.
4. Press the Run/play button to execute the code and listen to the composition.

## Room for Improvement 
* Chord arrangement algorithm: The current algorithm selects chord inversions based on the smallest movement from the immediately preceding chord. This could be improved by considering the entire progression to find the smoothest overall arrangement.
* Musical complexity: Additional musical layers, variations and transitions could be introduced to create a more developed and dynamic composition.
* Code efficiency: Some sections of the code could be further simplified by developing additional reusable functions and reducing repeated instructions.
